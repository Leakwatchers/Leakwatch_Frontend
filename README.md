# Leakwatch Frontend

**Interface web para monitoramento de vazamentos utilizando IoT**

---

## Sobre o projeto

O Leakwatch Frontend é a interface web do projeto Leakwatch, responsável pela visualização e interação com os dados coletados pelos dispositivos IoT.

A aplicação foi desenvolvida utilizando JavaScript, Vite, HTML e CSS, integrando-se à API back-end do projeto.

- Interface para monitoramento dos dispositivos
